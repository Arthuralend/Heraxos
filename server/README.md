# Heraxos — защищённые звонки и сообщения

## Установка на сервер 82.26.86.235
    scp heraxos.tar.gz root@82.26.86.235:/root/
    ssh root@82.26.86.235
    tar xzf heraxos.tar.gz && cd heraxos && sudo bash install.sh

В конце скрипт покажет:
- адрес приложения: https://82-26-86-235.sslip.io:8445
- адрес админки:    https://82-26-86-235.sslip.io:8445/admin.html
- пароль администратора (хранится в /opt/heraxos/.env, строка ADMIN_PASSWORD)

Если раньше ставили «Звонки», скрипт сам их отключит и заменит на Heraxos.
Порты 443, 8443, 8090 не используются. Нужны: 8445/tcp, 3478 tcp+udp, 5349/tcp,
49160–49200/udp, а 80/tcp — только для выпуска и продления сертификата.

## Безопасность
- Сообщения: сквозное шифрование ECDH P-256 + AES-256-GCM. Ключ создаётся на телефоне;
  на сервер уходит только зашифрованный паролем пользователя (PBKDF2, 600 000 итераций).
  В базе лежит лишь шифротекст: ни администратор, ни владелец сервера прочитать его не могут.
- Звонки: DTLS-SRTP (стандарт WebRTC), ничего не записывается.
- Админ может только: добавить пользователя, удалить, сбросить пароль.
  После сброса пароля старая переписка этого пользователя становится нечитаемой
  (так устроено шифрование: старый ключ был защищён старым паролем).

## Контакты
Общего списка пользователей нет. Чтобы общаться, нужно добавить человека по точному логину
(вкладка «Контакты» → «Добавить»), он получит заявку. После «Принять» вы появляетесь друг у друга
в контактах и можете переписываться и звонить. Без взаимного добавления сервер не пропустит
ни сообщение, ни звонок.

## Качество
- Звук: Opus 48 кГц, 128 кбит/с, FEC (устойчивость к потерям), подавление эха и шума.
- Видео: VP9 → H.264 → VP8 (что поддерживает устройство). По умолчанию 540p;
  во время звонка кнопкой качества можно выбрать 360p / 540p / 720p / 1080p
  (применяется у обоих собеседников). Значение по умолчанию меняется в «Настройках».

## iPhone
Safari → «Поделиться» → «На экран Домой» → открыть Heraxos со значка → войти →
разрешить уведомления. Нужен iOS 16.4+. Входящий звонок приходит уведомлением
(полноэкранный вызов как у WhatsApp доступен только приложениям из App Store).

## Управление
    systemctl restart heraxos     # перезапуск
    journalctl -u heraxos -f      # логи
    /opt/heraxos/data/db.json     # база (только зашифрованные сообщения)
