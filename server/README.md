# Ahazang — защищённые звонки и сообщения

## Установка на сервер (ahazang.klegal.ru → 195.10.205.90)
DNS: A-запись `ahazang.klegal.ru` → `195.10.205.90` (уже добавлена).

**1. Перенос данных со старого сервера** (если нужен). На старом сервере 82.26.86.235:

    tar czf /root/ahazang-data.tgz -C /opt/heraxos data .env
    scp /root/ahazang-data.tgz root@195.10.205.90:/root/

**2. Установка на новом сервере** 195.10.205.90:

    cd /root && curl -sL https://github.com/Arthuralend/Heraxos/archive/refs/heads/main.tar.gz | tar xz
    cd Heraxos-main/server && sudo bash install.sh

Ограничить админку своими IP (необязательно): `ADMIN_IPS="1.2.3.4" sudo -E bash install.sh`.

В конце скрипт покажет адрес админки и пароль администратора (хранится в `/opt/ahazang/.env`).
Порты: 80/tcp (сертификат), 443/tcp (приложение), 3478 tcp+udp и 5349/tcp (звонки через посредника),
40000–49999/udp (звук и видео через посредника).

**Обновление сервера** после изменений в репозитории:

    cd /tmp && rm -rf hx && mkdir hx && curl -sL https://github.com/Arthuralend/Heraxos/archive/refs/heads/main.tar.gz | tar xz -C hx --strip-components=1 && cp hx/server/server.js /opt/ahazang/ && cp -r hx/server/public/. /opt/ahazang/public/ && systemctl restart ahazang

**Управление:** `systemctl restart ahazang`, журнал — `journalctl -u ahazang -f`,
копии базы — `/var/backups/ahazang` (каждый день, 14 дней).

## Доступ
Интерфейс и API отдаются только приложениям Ahazang (Android и iPhone). В браузере по адресу
сервера открывается страница «Скачайте приложение». Админка — `https://ahazang.klegal.ru/admin.html`
(по паролю; при ADMIN_IPS — только с указанных адресов). Временно открыть интерфейс и в браузере:
`ALLOW_WEB=1` в `/opt/ahazang/.env` и перезапуск.

## Файлы
Файлы шифруются на телефоне (AES-256-GCM, случайный ключ на каждый файл), на сервер попадает
только шифротекст (`/opt/ahazang/data/files`). Ключ уходит собеседнику внутри зашифрованного
сообщения. До 100 МБ на файл (`MAX_FILE_MB`), хранятся 365 дней (`FILE_DAYS`).

## Ключ подписи Android
Ключ не хранится в репозитории. В GitHub → Settings → Secrets and variables → Actions нужны:
`ANDROID_KEYSTORE_B64` (файл ключа в base64) и `ANDROID_KEYSTORE_PASSWORD`.

## Безопасность
- Сообщения: сквозное шифрование ECDH P-256 + AES-256-GCM. Ключ создаётся на телефоне;
  на сервер уходит только зашифрованный паролем пользователя (PBKDF2, 600 000 итераций).
  В базе лежит лишь шифротекст: ни администратор, ни владелец сервера прочитать его не могут.
- Звонки: DTLS-SRTP (стандарт WebRTC), ничего не записывается.
- Админ может только: добавить пользователя, удалить, сбросить пароль.
  После сброса пароля старая переписка этого пользователя становится нечитаемой
  (так устроено шифрование: старый ключ был защищён старым паролем).

## Контакты
Общего списка пользователей нет. Чтобы общаться, нужно добавить человека по точному логину
(вкладка «Контакты» → «Добавить»), он получит заявку. После «Принять» вы появляетесь друг у друга
в контактах и можете переписываться и звонить. Без взаимного добавления сервер не пропустит
ни сообщение, ни звонок.

## Качество
- Звук: Opus 48 кГц, 64 кбит/с, пакеты 20 мс, FEC + RED (устойчивость к потерям), подавление эха и шума;
  голос в приоритете над видео (видео стартует с ~800 кбит/с и поднимается по мере возможности канала).
- Видео: VP9 → H.264 → VP8 (AV1 отключён). По умолчанию 1080p:
  при слабом интернете WebRTC сам снижает битрейт и разрешение, при хорошем — возвращает 1080p.
  В групповом звонке видео до 540p. Во время звонка кнопкой качества можно ограничить 720p / 540p / 360p.
- Каждые 15 с звонка в журнал сервера пишется замер: путь (напрямую / через сервер), задержка, потери и рывки звука.
- Связь восстанавливается при смене сети (ICE restart); при сворачивании приложения звонок продолжается
  (Android: служба с типом «микрофон/камера»; сервер выводит из звонка только если у человека нет
  ни одного соединения дольше 60 секунд).

## Обновления
- Интерфейс приходит с сервера: после обновления сервера приложения перезагружают его сами и показывают «Что нового».
- Android: приложение проверяет последний выпуск на GitHub и предлагает скачать новую версию
  («Настройки → Обновление приложения»). Текст изменений берётся из `CHANGES.md` в корне репозитория —
  обновляйте его перед каждой сборкой.

## iPhone: звонки при закрытом приложении (PushKit + CallKit)
Сервер будит iPhone VoIP-сигналом через Apple, iOS показывает системный экран входящего звонка.
Нужен ключ APNs (developer.apple.com → Keys → «+» → Apple Push Notifications service). На сервере:

    nano /opt/ahazang/apns.p8          # вставить весь текст файла AuthKey_XXXXXXXXXX.p8, сохранить
    chmod 600 /opt/ahazang/apns.p8
    printf 'APNS_KEY_FILE=/opt/ahazang/apns.p8\nAPNS_KEY_ID=XXXXXXXXXX\nAPNS_TEAM_ID=YYYYYYYYYY\n' >> /opt/ahazang/.env
    systemctl restart ahazang && journalctl -u ahazang -n 5 --no-pager | grep apns

В журнале должно быть «[apns] включено». Без ключа iPhone получает звонки только при открытом приложении.
