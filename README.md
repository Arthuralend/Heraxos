# Heraxos

Защищённые звонки и сообщения на собственном сервере.

- `server/` — сервер и веб-приложение (Node.js, WebRTC, сквозное шифрование чатов, TURN, админ-кабинет). Установка: `server/README.md`.
- корень репозитория — приложение для Android: вход по логину и паролю, входящий звонок на весь экран с рингтоном и вибрацией, работа без Google-сервисов.

**Скачать Android-приложение:** [Heraxos.apk](https://github.com/Arthuralend/Heraxos/releases/latest/download/Heraxos.apk)

APK собирается автоматически (GitHub Actions) при каждом изменении в ветке `main`.
